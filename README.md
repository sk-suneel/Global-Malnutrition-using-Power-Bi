# Global Malnutrition Analysis Dashboard

An interactive **Power BI dashboard** that analyzes global malnutrition trends across different countries, age groups, genders, and years. This project transforms raw data into meaningful visual insights to support data-driven decision-making.

---

## Project Overview

Malnutrition remains one of the world's most significant public health challenges. This dashboard helps visualize malnutrition trends, identify high-risk regions, and compare indicators across multiple dimensions.

The dashboard enables users to:
- Monitor global malnutrition trends
- Compare countries and regions
- Analyze gender-wise and age-wise statistics
- Identify high-risk populations
- Make data-driven decisions using interactive visualizations

---

## Dashboard Features

- Trend Analysis over time
- Country & Region comparison
- Gender-wise analysis
- Age-group analysis
- KPI Cards
- Interactive slicers and filters
- Dynamic charts and visualizations
